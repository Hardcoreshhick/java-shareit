# ShareIt — Сервис для шеринга вещей

**ShareIt** — это backend-приложение, разработанное в рамках финального спринта курса Java-разработчик в Яндекс Практикуме. Сервис позволяет пользователям делиться своими вещами, брать их в аренду, оставлять отзывы и создавать запросы на поиск нужных вещей.

## Архитектура: Микросервисы

В этом спринте проект был разделен на два независимых приложения (модуля), которые общаются друг с другом по REST API. Это позволяет разгрузить основной сервер и легко масштабировать систему.

1. **`shareit-gateway`** (порт `8080`) — шлюз, который принимает все запросы от клиентов. В нем происходит **валидация** входящих данных (чтобы плохие данные не нагружали базу). После проверки запрос проксируется на сервер.
2. **`shareit-server`** (порт `9090`) — основное приложение, содержащее всю бизнес-логику и работающее с базой данных (PostgreSQL).

## Основной функционал (API)

- **Пользователи (`/users`)** — CRUD-операции (создание, чтение, обновление, удаление).
- **Вещи (`/items`)** — добавление вещей, поиск, просмотр с комментариями и датами бронирования.
- **Бронирование (`/bookings`)** — создание брони, подтверждение владельцем, просмотр истории.
- **Комментарии** — отзывы к вещам после окончания срока аренды.
- **Запросы на вещи (`/requests`)** — создание запросов на поиск вещей и возможность откликаться на чужие запросы (связь вещи с запросом через `requestId`).

## Стек технологий

- **Java 21**, **Spring Boot 3.3.2**
- **Spring Web**, **Spring Data JPA**, **Hibernate**
- **PostgreSQL** (основная БД), **H2** (для тестов)
- **MapStruct** (маппинг DTO и Entity)
- **Maven** (многомодульная сборка)
- **Docker / Docker Compose**
- **Postman** (коллекция тестов для проверки API)
